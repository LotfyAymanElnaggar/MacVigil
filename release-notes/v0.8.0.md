# MacVigil v0.8.0

## Smart Job Guard suggestions

Job Guard can now recognize common long-running developer workloads that are already running on your Mac and surface them as **suggestions**.

Examples include:

- AI coding agents and agent CLIs
- Ollama, LM Studio, llama.cpp, MLX and other local-AI runtimes
- Xcode/Swift, Rust, Gradle, Maven, CMake and Ninja build processes
- Docker, Colima, Podman, OrbStack and related container runtimes
- common local development servers
- long-running transfer tools such as rsync and rclone

MacVigil scans the local process list and groups likely workloads by type. Suggestions appear at the top of Job Guard so you can protect one without searching through every process.

**Detection is advisory and opt-in.** MacVigil never starts Vigil or attaches Job Guard to a detected process without you choosing it.

## Job Guard polish

- detected workloads are labeled by category
- the menu-bar panel shows when likely workloads are available to review
- search can match workload categories as well as process names and PIDs
- the full process picker remains available for anything MacVigil does not recognize
- manual PID watching and command-based Job Guard continue to work as before

## Better GitHub releases

Starting with v0.8.0, MacVigil releases use curated, versioned release notes from the repository instead of publishing only an automatically generated commit summary.

The DMG and SHA-256 checksum remain attached to every release.

## Updating

If you are on v0.7.0 with automatic update checks enabled, MacVigil should discover v0.8.0 in the background. You can also choose **Check Now** from Updates and install it manually.

MacVigil is still ad-hoc signed rather than Developer ID notarized, so macOS may require approval from **Privacy & Security** on first launch or after a manual replacement.

## Notes

Smart workload detection is intentionally heuristic. It will not recognize every development process, and a suggestion does not guarantee that the process should be kept awake. Use the normal process picker whenever you want explicit control.
